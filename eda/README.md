# Exploratory Data Analysis

Thư mục này chứa notebook phân tích và trực quan hoá dữ liệu thời tiết Hà Nội.

```text
eda/
├── data_analyze.ipynb
├── eda_visualization.ipynb
└── README.md
```

## File Chính

| Notebook | Vai trò |
|---|---|
| `data_analyze.ipynb` | Kiểm tra thống kê mô tả, missing values, tương quan và tổng hợp theo giờ/tháng. |
| `eda_visualization.ipynb` | Vẽ biểu đồ time series, phân phối, seasonality, heatmap tương quan và quan hệ giữa các biến thời tiết. |

## Input

- `../data/processed/Hanoi_final.csv`
